# HeySea — демо складних анімацій (запит дизайнерки)

Легкий варіант без адмінки: PHP (дані масивами, як потім ACF) + CSS + vanilla JS (GSAP, d3-geo). Усі бібліотеки лежать локально у `vendor/`, зовнішніх запитів немає (важливо для Китаю).

Запуск: `./serve.sh`, далі відкрити http://localhost:8790. Щоб показати одну секцію: `?only=timeline`, `?only=globe` тощо.

Статична версія (без PHP): `./build-static.sh` збирає `docs/`: `index.html` з усіма секціями і `<slug>.html` для кожної. Саме `docs/` віддає GitHub Pages (Settings → Pages → Branch `main`, папка `/docs`). Індексацію заборонено (`noindex`, `robots.txt`).
